mart Ludo Multiplayer Engine

A complete multiplayer Ludo game developed in Python featuring a graphical user interface, turn-based gameplay, dice mechanics, and AI-controlled bot players.

Project Overview

Smart Ludo Multiplayer Engine recreates the classic Ludo board game using Python. The project demonstrates game development concepts such as board management, player turns, token movement, collision handling, and artificial intelligence for automated gameplay.

The game supports multiple players and includes a bot player capable of making automated decisions during gameplay.
